How to Install Mods?

1. Install the Mod Loader for the Right Version help can be provided by asking in the Group of our current Messager. Important is that the Version has to have been played.

2. Install the Mods on the right Version e.g. Fabric 1.20.1

3. Have your ".jar" Files ready

4. Either you press "Windows + R" and enter "%AppData%" or you just enter it into the Search Bar in Windows File Explorer

5. Locate the ".minecraft" Folder and in there find the "mods" Folder if there is non create a folder called "mods"

6. Now move or Copy the ".jar" Files to the %AppData%/.minecraft/mods/

7. Open the Minecraft Launcher and select the Profile of the Modloader

7.5 (This step is optinal) Rename the Profile to the Loader Name (e.g. Fabric) + the Version (e.g. 1.20.1)

8. Start Minecraft, if it crashes most modloaders will show what Mods could be missing.

This process can be skipped by just using Modrinth Launcher for Exsample as it automaticly installs all dependencies with the Mod.
