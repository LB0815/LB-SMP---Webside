What host are we using?

We are currently using Aternos as it is free

Why use the current Host?

Good Points

  • It's Free
  • Mod Support

Bad Points

  • World deletion
  • Low Simulation distance (3)
  • Ads
  • Session On

What is "World deletion"

As we are using Aternos, after 30 Days of not playing, the Server will be deleted. But we can still restore the world file so not all hope is lost.

What is "Session On"

On Aternos, you need to start the server, then you have an 6min Window for anyone to join. If one or more player/-s are online the server will stay online, but if non are online, then the Server will turn off after two minutes
